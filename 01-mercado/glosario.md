# Glosario — jerga del polo y los caballos

> **Regla:** en el producto, en el bot de WhatsApp y en todo el contenido usamos estos términos. El bot tiene que **entenderlos** (y sus variantes) y **hablar** así. Sumar términos nuevos cuando aparezcan en entrevistas.

## Juego

| Término | Significado |
|---|---|
| **Chukker** | Período de juego de 7 minutos. Un partido tiene 4 a 8 |
| **Handicap** | Valoración del jugador de -2 a 10 goles. El del equipo es la suma |
| **Alto / mediano / bajo handicap** | Categorías de torneo según el handicap del equipo. *High goal* = alto |
| **Taco** | El palo/mazo con el que se pega |
| **Bocha** | La pelota |
| **Taquear / taqueada** | Practicar pegándole a la bocha a caballo |
| **Práctica** | Partido de entrenamiento |
| **Abierto / Open** | Torneo abierto de alto handicap (ej. Abierto de Palermo) |
| **Triple Corona** | Tortugas + Hurlingham + Abierto Argentino de Palermo |
| **Patrón** | Dueño/financista del equipo que contrata profesionales. Suele jugar en el equipo |
| **Acuerdo (con un patrón)** | Lo que el polista "arregló" cobrar por jugar una temporada; se cobra en pagos parciales (seña, transferencias) |
| **Lo cubre el patrón / reintegro** | Gasto que paga el polista y le devuelve el patrón (ej. flete aéreo, pasajes de petiseros) |
| **Pago del handicap** | Cuota anual a la asociación que asigna el handicap (AAP en Argentina, **HPA** en Inglaterra) |
| **HPA** | Hurlingham Polo Association, asociación de polo de Inglaterra |
| **Temporada** | Período de juego en un lugar (Argentina, Inglaterra, Sotogrande, Wellington); en el producto, filtro de período y resultado por temporada |
| **Profesional** | Polista que cobra por jugar |
| **Organización** | El "equipo empresa" de un polista: caballos, petiseros, instalaciones, logística |

## Caballos

| Término | Significado |
|---|---|
| **Petiso** | Caballo de polo (aunque no sea chico) |
| **Crack** | Caballo excepcional |
| **Yegua / caballo / padrillo** | Hembra / macho castrado (en la jerga general "caballo") / macho entero reproductor |
| **Potrillo / potranca** | Cría macho / hembra joven |
| **Verde** | Caballo con poca doma, todavía no "hecho" |
| **Hecho / a medio hacer** | Nivel de doma: listo para jugar / en proceso |
| **Doma** | Proceso de amansar y entrenar al caballo |
| **Pelaje** | Color del caballo (zaino, alazán, tordillo, moro, overo, colorado, picazo, bayo…) |
| **Marca** | Marca a fuego del propietario/haras |
| **Polo Argentino** | Raza; registro en AACCP (Asociación Argentina de Criadores de Caballos de Polo) |
| **App Polo Argentino** | App **de terceros** (App Store) con la información de los caballos de polo registrados. Posible integración para traer los datos de los caballos. **No es nuestro producto**, que todavía no tiene nombre |
| **ET / clonación / ICSI** | Técnicas reproductivas (transferencia embrionaria, clonación, inyección intracitoplasmática); ~90% de los nacimientos de polo actuales |
| **Donante / receptora** | Yegua que aporta el embrión / yegua que lo gesta (transferencia embrionaria) |
| **Servicio** | Monta o inseminación de un padrillo |
| **Lesionado / parado / en descanso / a campo** | Estados del caballo fuera de juego |
| **Estados en el producto** | **Jugando** (en la caballeriza, en trabajo), **En el campo**, **Exterior**, **Recuperación** |
| **Retirada · madre** | Yegua que ya no juega y se usa para cría |
| **Renguera / renguear** | Cojera; novedad típica que reporta un petisero |
| **Cólico** | Problema digestivo grave; "post cólico" = en recuperación |
| **En trabajo / en vaso** | Caballo en preparación activa para jugar |

## Caballeriza y gente

| Término | Significado |
|---|---|
| **Petisero** | Persona que cuida, alimenta, varea y prepara los caballos |
| **Piloto** | El mayor de los petiseros, encargado de la caballeriza: coordina petiseros, herrero, veterinaria y stock. En el producto usamos **piloto** (no "encargado"). Solo usa WhatsApp |
| **Manager** | Mano derecha del polista en organizaciones grandes. Registra todo (caballeriza, stock, vete, herrero, cada yegua). Ve lo mismo que el polista en la app |
| **Grupo (de la organización)** | Grupo de WhatsApp donde están el manager, el polista, el vete, el herrero y algún petisero; ahí está el bot |
| **Puestero** | Persona que vive y trabaja en el campo y cuida los caballos que están ahí |
| **Capataz / jefe de petiseros** | Coordina petiseros y caballeriza (similar a piloto) |
| **Caballeriza / box / stud** | Instalación donde están los caballos |
| **Pensión** | Pagar para que un tercero tenga y cuide tus caballos |
| **Potrero** | Lote de campo donde pastan los caballos |
| **Campo** | Establecimiento rural donde van los caballos que descansan, se doman, las madres y las retiradas (en el mockup: Cnel. Suárez) |
| **Invernada** | Dejar caballos en el exterior entre temporadas (en el mockup: Windsor) |
| **Pastoreo** | Pagar para que los caballos pasten en un campo ajeno (típico en temporadas afuera) |
| **Box** | Compartimento individual de la caballeriza. "Quedó en el box" = no sale a trabajar |
| **Paddock** | Corral/potrero chico (término inglés usado afuera) |
| **Embocadura** | Bocado o freno del caballo ("probar la de goma") |
| **Bozal** | Cabezada sin freno; en Gastos: categoría "Bozales y riendas" |
| **Varear / vareo / vareada** | Ejercitar al caballo (montado o llevando varios de tiro desde otro caballo). En el producto: "vareada hoy", "12 de 14 vareados". *(Antes figuraba como "vasear": el término que usamos es varear)* |
| **Herrero / herrador** | Hierra los caballos (cada ~4–6 semanas) |
| **Herraje / herrar / despalmar** | Poner herraduras / emparejar el casco sin herrar |
| **Vete** | Veterinario |
| **Talabartería** | Monturas, cabezadas, riendas, equipo de cuero |
| **Corralón / forrajería** | Proveedor de avena, fardos, viruta, balanceado |
| **Fardo / rollo** | Alfalfa o pasto enfardado: el fardo es chico, el rollo pesa ~400 kg (se usa en el campo) |
| **Viruta** | Cama de los boxes |
| **Trailer / camión** | Transporte de caballos; si es contratado, es un **flete de caballos** |
| **Recado / montura** | Silla de montar |
| **Cabezada, bocado, riendas, gamarra, vendas, protectores** | Equipamiento del caballo |

## Sanidad y documentación (Argentina)

| Término | Significado |
|---|---|
| **AIE (anemia infecciosa equina)** | Análisis obligatorio periódico para mover y exportar caballos (modelo de certificado: Res. 633/2024) |
| **Microchip** | Identificación electrónica; obligatorio para trasladar desde el 1/3/2027 (Res. 831/2026; especificación en Res. 530/2025) |
| **Libreta Sanitaria Equina Digital** | Reemplaza la libreta de papel; en SIGSA o "aplicaciones autorizadas" (Res. 831/2026) |
| **Pasaporte Equino Digitalizado** | Documento de identidad del caballo (Res. 831/2026) |
| **SIGSA** | Sistema de gestión sanitaria de SENASA |
| **DT-e** | Documento de tránsito electrónico (sigue para exportar/importar) |
| **CVI** | Certificado Veterinario Internacional, lo emite SENASA para exportar |
| **Cuarentena** | Aislamiento previo a exportar, según destino |
| **SENASA** | Organismo sanitario; documentación de tránsito de equinos |
| **Vacunas** | Influenza, encefalomielitis, tétanos, etc. |
| **Desparasitación** | Tratamiento antiparasitario periódico |
| **Pasaporte / libreta sanitaria** | Documentación del caballo (clave para viajar afuera) |

## Plata (cómo hablan los montos)

| Expresión | Significa |
|---|---|
| **Luca(s)** | Mil pesos ("50 lucas" = $50.000) |
| **Palo / un palo** | Un millón de pesos |
| **Verdes / dólares / USD** | Dólares |
| **Blue / MEP** | Tipos de cambio del dólar en Argentina |
| **Cash / en mano / efectivo** | Pago sin transferencia |
| **Cuenta corriente** | Deuda con el proveedor (forrajería, herrero) que se paga a fin de mes |
| **Seña** | Anticipo al cerrar un acuerdo o reservar algo (ej. seña de caballeriza para la próxima temporada) |
| **Pagos fijos** | Gastos que se repiten todos los meses (sueldos, alquileres, invernada) |
| **US$ / $ / € / £** | Dólares, pesos, euros, libras. En el producto **todo se muestra en US$**; un gasto en $ o € se convierte y se aclara en letra chica |
| **Dólar blue** | Cotización informal del dólar en Argentina. Es la que usamos para pasar pesos a dólares (la del día en que llega el gasto) |
