# Glosario — jerga del polo y los caballos

> **Regla:** en el producto, en el bot de WhatsApp y en todo el contenido usamos estos términos. El bot tiene que **entenderlos** (y sus variantes) y **hablar** así. Sumar términos nuevos cuando aparezcan en entrevistas.

## Juego

| Término | Significado |
|---|---|
| **Chukker** | Período de juego de 7 minutos. Un partido tiene 4 a 8 |
| **Handicap** | Valoración del jugador de -2 a 10 goles. El del equipo es la suma |
| **Alto / mediano / bajo handicap** | Categorías de torneo según el handicap del equipo. *High goal* = alto |
| **Taco** | El palo/mazo con el que se pega |
| **Bocha** | La pelota |
| **Taquear / taqueada** | Practicar pegándole a la bocha a caballo |
| **Práctica** | Partido de entrenamiento |
| **Abierto / Open** | Torneo abierto de alto handicap (ej. Abierto de Palermo) |
| **Triple Corona** | Tortugas + Hurlingham + Abierto Argentino de Palermo |
| **Patrón** | Dueño/financista del equipo que contrata profesionales. Suele jugar en el equipo |
| **Profesional** | Polista que cobra por jugar |
| **Organización** | El "equipo empresa" de un polista: caballos, petiseros, instalaciones, logística |

## Caballos

| Término | Significado |
|---|---|
| **Petiso** | Caballo de polo (aunque no sea chico) |
| **Crack** | Caballo excepcional |
| **Yegua / caballo / padrillo** | Hembra / macho castrado (en la jerga general "caballo") / macho entero reproductor |
| **Potrillo / potranca** | Cría macho / hembra joven |
| **Verde** | Caballo con poca doma, todavía no "hecho" |
| **Hecho / a medio hacer** | Nivel de doma: listo para jugar / en proceso |
| **Doma** | Proceso de amansar y entrenar al caballo |
| **Pelaje** | Color del caballo (zaino, alazán, tordillo, moro, overo, colorado, picazo, bayo…) |
| **Marca** | Marca a fuego del propietario/haras |
| **Polo Argentino** | Raza; registro en AACCPA |
| **Donante / receptora** | Yegua que aporta el embrión / yegua que lo gesta (transferencia embrionaria) |
| **Servicio** | Monta o inseminación de un padrillo |
| **Lesionado / parado / en descanso / a campo** | Estados del caballo fuera de juego |
| **En trabajo / en vaso** | Caballo en preparación activa para jugar |

## Caballeriza y gente

| Término | Significado |
|---|---|
| **Petisero** | Persona que cuida, alimenta, vasea y prepara los caballos |
| **Capataz / jefe de petiseros** | Coordina petiseros y caballeriza |
| **Caballeriza / box / stud** | Instalación donde están los caballos |
| **Pensión** | Pagar para que un tercero tenga y cuide tus caballos |
| **Potrero** | Lote de campo donde pastan los caballos |
| **Vasear** | Ejercitar caballos llevándolos de tiro (varios a la vez) desde otro caballo |
| **Herrero / herrador** | Hierra los caballos (cada ~4–6 semanas) |
| **Herraje / herrar / despalmar** | Poner herraduras / emparejar el casco sin herrar |
| **Vete** | Veterinario |
| **Talabartería** | Monturas, cabezadas, riendas, equipo de cuero |
| **Recado / montura** | Silla de montar |
| **Cabezada, bocado, riendas, gamarra, vendas, protectores** | Equipamiento del caballo |

## Sanidad y documentación (Argentina)

| Término | Significado |
|---|---|
| **AIE (anemia infecciosa equina)** | Análisis obligatorio periódico para mover caballos |
| **SENASA** | Organismo sanitario; documentación de tránsito de equinos |
| **Vacunas** | Influenza, encefalomielitis, tétanos, etc. |
| **Desparasitación** | Tratamiento antiparasitario periódico |
| **Pasaporte / libreta sanitaria** | Documentación del caballo (clave para viajar afuera) |

## Plata (cómo hablan los montos)

| Expresión | Significa |
|---|---|
| **Luca(s)** | Mil pesos ("50 lucas" = $50.000) |
| **Palo / un palo** | Un millón de pesos |
| **Verdes / dólares / USD** | Dólares |
| **Blue / MEP** | Tipos de cambio del dólar en Argentina |
| **Cash / en mano / efectivo** | Pago sin transferencia |
| **Cuenta corriente** | Deuda con el proveedor (forrajería, herrero) que se paga a fin de mes |
